# High View Farm

Simple static website for **High View Farm** at 524 Winery Lane, Roseland, Virginia — `highview.farm`.

Stays are booked through the [Airbnb listing](https://www.airbnb.com/rooms/944918152360778142). The site also introduces the farm as a place for small gatherings.

## Preview locally

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080

## Next: GitHub, then the domain

The design lives in this git repo first. When you are ready:

1. Create a GitHub repository and push this folder.
2. Deploy with GitHub Pages, Netlify, or Vercel (any of these work for a static site).
3. Point the `highview.farm` domain at that host.

Photos are saved locally in `images/` so the live site does not depend on Airbnb.
